# Папка модов

Сюда кладём `.jar` файлы модов для **Fabric 1.21.4**.

Лаунчер при запуске игры:
1. находит моды в этой папке (или рядом с `.exe` в подпапке `mods`);
2. копирует новые/обновлённые моды в `<папка игры>\mods`;
3. запускает Fabric-версию с ними.

Важно:
- моды должны быть под Fabric 1.21.4;
- если используешь Fabric API — не дублируй его (один файл `fabric-api-*.jar`);
- файлы `.jar.disabled` игнорируются.

Чтобы увидеть список, открой в лаунчере раздел **Моды**.
