# Встроенные моды (локальная папка)

В публичном репозитории эта папка пуста — `.jar` здесь намеренно не хранятся.

Лаунчер вшивает всё содержимое `embedded/*.jar` в exe как `EmbeddedResource`
и при каждом запуске восстанавливает файлы в `<папка игры>/mods` в режиме
«только для чтения».

Чтобы собрать полную версию, положите нужные `.jar` сюда — `csproj` подхватит
их автоматически. Без них проект тоже собирается и запускается, просто не
устанавливает обязательные моды.
